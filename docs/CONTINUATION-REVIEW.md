# 開発引継ぎ（2026-10-16）

## 目的と現在地

日本語の長文を安全に編集するiPhone向けプロトタイプです。最優先は未保存本文、Undo、日本語IME、既存ファイルの保護です。機能・構成は[README](../README.md)、保存境界は[アーキテクチャ](ARCHITECTURE.md)を参照してください。

基準コミットは `1ff6667e0d18f965072a46921be3fd87c35876c0`、継続ブランチは `django` です。再開時には `git status --short`、`git branch --show-current`、`git rev-parse HEAD` で実値を確認してください。この文書追加時点でAGENTS.mdはありません。

実機での起動と日本語入力はユーザー報告で確認済みです。最新の保存・再読込アイコン修正はまだ実機へインストール・確認されていません。Simulator試験は実機の合格を意味しません。

## 今日の変更

- 保存やIME案内で本文欄が上下する問題を修正。通知領域を固定し、詳細な進行・取消操作は保存詳細へ保持しました。
- 通常保存時のfooter文言とアイコンを固定し、回転表示を削除。失敗・競合・結果不明の表示は残しました。
- ユーザーが大きな青い保存ボタンの有効/無効切替をちらつき原因と特定したため、小さい保存アイコンへ変更。タップ領域44×44pt、アクセシビリティ名は「保存」。busy中も外観を変えず、タップは追加保存を開始しません。競合・結果不明・ロック時の制限、初回保存先選択は維持します。
- 再読込も44×44ptのアイコンに変更。VoiceOver名は「再読込」。通常busyで外観を変えず、busy/IME中タップを拒否します。保存先なし・ロック時の制限、未保存本文の比較・保護、競合/結果不明時の既存再読込経路は保持しました。
- 表示寸法、本文ビューへの不要な再代入、保存アイコンの画像一致、処理中タップと重複保存の回帰試験を追加しました。

## 構成と変更時の注意

`Editor/` がUITextViewの本文・選択・Undoを所有します。`Core/` のJavaScriptをNodeとJavaScriptCoreで共用し、`App/` が保存処理を実行します。`Storage/` は下書き、偽保存先、Filesアダプタ、`UI/` は表示と操作の入口です。保存完了で本文を古いスナップショットに差し戻さないことが重要です。

保存ボタンは `UI/EditorScreen.swift` の `SaveIconButton`。外観の無効条件と、実行直前のbusy/IMEガードを分離しています。処理中のタップは予約されず、実行済み表示もしません。画面、controller、coreの既存ガードを外さないでください。

## 検証と既知制限

MacでNode119件、Native55件、署名なしSimulator Debugテスト・Releaseビルドが成功しました。コマンドと試験範囲は[検証記録](VALIDATION.md)、環境手順は[Mac手順](MAC-VALIDATION.md)を参照してください。WindowsでのNode119件成功とは別の実行結果です。

通常の保存先はアプリ内の偽プロバイダです。Filesは既定無効で、新規・別名保存のFiles対応はありません。Google Drive本番保存、クラウド反映、実Filesのscope/coordination/bookmark、強制終了後の実機保持、実機の低容量・長文性能は未検証です。NativeのIME試験は模擬marked rangeを含み、実キーボードでの変換品質を保証しません。

GUI自動操作では繰り返し承認が発生したため、実機操作はユーザーによる手動確認へ切り替えました。今回の検証はCLIと分離Simulatorに限定し、実機の更新・再起動・既存下書きには触れていません。

## ローカル設定と公開版

公開版projectは署名無効の汎用設定を保持します。既存Macでユーザーが設定したprojectの署名設定とInfo.plistの整形変更は作業ツリーに保持し、コミット対象から除外しました。Info.plistの意味上の変更はありません。projectの差分は署名設定とrunpath表現の変更です。

このため、そのMacではコミット後も2ファイルのローカル差分が残ります。`git add -A`、projectの再生成、resetやcheckoutによる上書きをしないでください。別の作業員は公開版から署名なしSimulatorで再開できます。実機署名は本人が管理します。CLI用の汎用例は `Tools/DeviceSigning.example.xcconfig`、個別設定は除外対象の `DeviceSigning.local.xcconfig` を使用します。既存のXcode設定をこのファイルへ自動移行したわけではありません。

認証情報、Team ID、端末識別子、証明書、秘密鍵、個人原稿、下書き、ログ、xcuserdataは公開しません。アカウント・規約・署名・セキュリティ設定の変更が必要なら、具体的な不足を報告して本人の操作を待ちます。
